راهنمای گذاشتن سلف‌ساز روی Railway (ساده و قدم‌به‌قدم)
=========================================================

⚠️ قبل از شروع: ربات داخل پایدروید رو کامل ببند (Stop). یک ربات با یک توکن
نباید همزمان دو جا روشن باشه. کاربرایی که روی پایدروید تست شدن، روی ریلوی
باید یک بار دوباره وارد بشن.

قدم ۱) گیت‌هاب
- وارد github.com شو ← New repository ← اسم: selfsaz ← حتماً Private ← Create.
- روی "uploading an existing file" بزن و این دو فایل رو آپلود کن:
    main.py
    requirements.txt
- Commit changes بزن.

قدم ۲) ریلوی
- railway.com ← New Project ← Deploy from GitHub repo ← همون selfsaz.
- اگه خودش دیپلوی کرد و خطا داد، مهم نیست؛ هنوز متغیرها رو نذاشتیم.

قدم ۳) متغیرها
سرویس رو باز کن ← تب Variables ← New Variable. این‌ها رو یکی‌یکی بساز:

    API_ID      = (عدد از my.telegram.org)
    API_HASH    = (از my.telegram.org)
    BOT_TOKEN   = (توکن ربات از @BotFather)
    OWNER_ID    = (آیدی عددی خودت از @userinfobot)
    DATA_DIR    = /data
    SECRET_KEY  = i4ZRjh40_XR4F26qeVcSY6-4HplxN0kMUt_rvs88fR8

(SECRET_KEY رو یه جا ذخیره کن و عوضش نکن؛ اگه عوض بشه همه کاربرا باید دوباره وارد بشن.)

قدم ۴) Volume (خیلی مهم، وگرنه با هر دیپلوی همه‌ی کاربرا پاک می‌شن)
- توی صفحه‌ی پروژه، راست‌کلیک روی بوم (یا دکمه‌ی + Create) ← Volume ← سرویس selfsaz رو انتخاب کن.
- Mount path رو بنویس:  /data

قدم ۵) دیپلوی دوباره
- Deploy ← Redeploy. تب Logs رو باز کن. باید ببینی:  ✅ ربات روشن شد
- (اختیاری) Settings ← Restart Policy ← Always.

قدم ۶) تست
- توی تلگرام برو ربات خودت ← /start ← شماره رو با دکمه بفرست ← کد رو با دکمه‌های عددی بزن.
- ثبت‌نام همون قبلیه (شماره ← کد ← رمز دومرحله‌ای اگه داشتی).
- ربات خودش یه پیام "روی سرور روشن شد" برای تو (OWNER_ID) می‌فرسته.

اگه خطا دیدی: متن Logs رو برام بفرست.
